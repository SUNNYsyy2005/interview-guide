# AI 应用与创业

## AI 产品设计
- 需求分析：用户调研、痛点挖掘、需求优先级（KANO 模型）
- 产品定义：MVP 设计、用户画像、核心用户旅程
- 竞品分析：功能对比矩阵、差异化定位、护城河分析
- AI 产品特殊性：数据飞轮、冷启动策略、人机协作设计
- 评估指标：用户留存、NPS、转化率、DAU/MAU

## AI 工程化落地
- 系统架构：前后端分离、微服务、API Gateway
- 模型服务化：模型部署（ONNX/TensorRT）、A/B 测试、灰度发布
- 性能优化：推理延迟优化、批量处理、缓存策略
- 监控告警：模型漂移检测、在线指标监控、异常报警
- 成本控制：GPU 资源调度、模型蒸馏/量化、Serverless 部署

## LLM 应用开发
- Prompt 工程：Few-shot、CoT、系统提示词设计、输出格式控制
- RAG 应用：文档解析、向量化、检索策略、重排序、答案生成
- Agent 应用：工具调用、多步推理、状态管理、错误恢复
- 对话系统：多轮对话管理、意图识别、槽位填充
- 质量保障：幻觉检测、事实性校验、人工评估流水线

## 数据工程
- 数据采集：爬虫、API、众包、遥操作
- 数据清洗：去重、质量过滤、异常检测
- 数据标注：标注规范设计、一致性校验、主动学习
- 数据管理：版本控制（DVC）、数据血缘、特征存储
- 合成数据：LLM 生成、数据增强、域随机化

## 商业模式与创业
- 商业模式：SaaS/API/平台/开源商业化
- 定价策略：按量计费/订阅制/阶梯定价
- 增长策略：PLG（产品驱动增长）、SLG（销售驱动增长）
- 融资认知：天使轮/Pre-A/A 轮、估值逻辑、投资人关注点
- 团队构建：技术/产品/市场角色分工、创始人互补性
- 风险分析：技术风险、市场风险、竞争风险、政策风险
