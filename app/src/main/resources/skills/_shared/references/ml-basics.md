# 机器学习基础

## 监督学习
- 线性回归：最小二乘法、正则化（L1/L2）、梯度下降 vs 正规方程
- 逻辑回归：sigmoid 函数、交叉熵损失、多分类 softmax
- SVM：最大间隔、核函数（RBF/多项式）、对偶问题、SMO 算法
- 决策树：信息增益/基尼系数、剪枝策略、CART/ID3/C4.5 区别
- 集成学习：Bagging（随机森林）vs Boosting（GBDT/XGBoost/LightGBM）
- KNN：距离度量、K 值选择、KD 树优化

## 无监督学习
- 聚类：K-Means（肘部法则/轮廓系数）、DBSCAN、层次聚类
- 降维：PCA（特征值分解/SVD）、t-SNE、UMAP
- 异常检测：孤立森林、One-Class SVM、LOF

## 模型评估与选择
- 评估指标：准确率/精确率/召回率/F1/AUC-ROC/PR 曲线
- 交叉验证：K-Fold、分层采样、时间序列特殊处理
- 偏差-方差权衡：欠拟合 vs 过拟合诊断
- 超参调优：网格搜索/随机搜索/贝叶斯优化

## 数学基础
- 概率论：贝叶斯定理、最大似然估计、MAP、先验/后验
- 线性代数：特征值分解、SVD、矩阵求导
- 优化理论：凸优化、梯度下降变体（SGD/Adam/AdaGrad）、学习率调度
- 信息论：交叉熵、KL 散度、互信息
